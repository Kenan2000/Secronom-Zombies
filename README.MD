*https://github.com/Erin105/Secronom-Zombies*

This is being developed with the latest experimental version of CDDA. It may have problems with stable or outdated experimental versions.
### How to install the mod:
1. Extract **Secronom-Zombies-master**.
2. Put _secronom_ into the mod folder of CDDA.
3. Done. Enjoy the mod!

### How to update your existing mod:
1. Delete _secronom_ mod from mod folder of CDDA.
2. Extract the latest **Secronom-Zombies-master**.
3. Put _secronom_ mod into the mod folder of CDDA.
4. Done.

###### Do this everytime you update as It is done to avoid errors.
